# 암종별 진료비·발생률·생존율·유병률 대시보드

국가암등록통계와 건강보험심사평가원의 공공데이터를 활용해, 암종별 발생률·생존율·유병률·진료비를 하나의 분석 흐름으로 묶고 Tableau 대시보드 2개로 시각화한 프로젝트입니다.

## 사용 데이터

- 국가암등록통계(국립암센터): 24개종 암발생률(1999~2023), 24개종 암 5년상대생존율(1993-1995~2019-2023, 5년 구간), 24개종 암 유병률(2023)
- 건강보험심사평가원: 암 상병 진료비 통계(2021~2025)

네 데이터셋은 암종 분류 체계가 서로 달라서(심평원 28개 암 상병명 vs 국립암센터 25개 암종), Colab에서 전처리하며 하나의 표준 암종 체계로 통일했습니다.

## 전처리 과정 (Google Colab)

1. 원본 CSV 8개(인코딩이 UTF-8/CP949로 제각각) 로드 및 구조 확인
2. 심평원 28개 암 상병명 → 국립암센터 25개 암종 매핑표 작성
   - 담낭암 + 담도암 → 국립암센터 기준에 맞춰 "담낭·담도"로 통합
   - 국립암센터 분류에 직접 대응이 없는 6개 항목(뼈 및 관절연골암, 소장암, 신우암, 요관암, 중피성연조직암, 피부암)은 국립암센터의 잔여 카테고리 "기타 암"으로 통합
3. ICD 코드 접두사("00. " 등) 정리
4. 결측치/중복행 점검, 진료비 이상값(보험자부담금 > 총액 등) 검증
5. 발생률 "모든암" 합계행과 개별 암종 합계를 교차검증해 매핑 정확도 확인
6. 성별 특이 암종(남자-자궁경부/자궁체부/난소, 여자-전립선/고환)의 구조적 결측치 확인 — 데이터 오류가 아니라 해당 성별에 존재하지 않는 암종이라 정상적으로 비어있는 값
7. 최종적으로 `cancer_cost.csv`, `cancer_incidence.csv`, `cancer_survival.csv`, `cancer_prevalence.csv` 4개 파일로 분리 저장 (표준화된 암종명을 공통 키로 사용 — 진료비 파일은 "표준암종", 나머지 세 파일은 "암종" 컬럼)

4개 테이블은 집계 단위(grain)가 서로 달라서(진료비: 연도×암종, 발생률: 연도×성별×암종, 생존율: 5년구간×성별×암종, 유병률: 단일연도×성별×암종) 하나로 합치지 않고, Tableau에서 Data Relationship으로 연결했습니다.

## 대시보드

### ① 암종별 종합 프로파일

![암종별 종합 프로파일 대시보드](../screenshots/암종별종합프로파일_대시보드.png)

암종 하나를 선택하면 그 암종의 발생률 추이, 생존율 추이, 유병률 현황, 최신 연도 진료비 총액(KPI)을 한 화면에서 확인할 수 있는 대시보드입니다.

예시로 간암을 보면, 2021~2025년 환자수는 약 2.3% 증가에 그쳤지만 진료비 총액은 약 23.9% 증가해 1인당 진료비가 상승하는 추세가 보이고, 발생률은 1999년 이후 꾸준히 감소(연령표준화발생률 52.4 → 20대 중후반 수준)하는 반면 5년상대생존율은 같은 기간 10%대에서 40%에 가까운 수준까지 개선됐습니다. 유병률은 남성이 여성의 약 3배(2023년 기준 63,947명 vs 21,740명)로, B형간염·음주 등 위험요인의 성별 차이와 일치합니다.

### ② 암종 간 비교

![암종 간 비교 대시보드](../screenshots/암종간비교_대시보드.png)

발생률(2023)·생존율(2019-2023)·유병률(2023)·진료비(2025) 네 지표 각각에서 상위 10개 암종을 막대로 비교하고, 발생률 1위 암종을 KPI로 보여주는 대시보드입니다.

갑상선암은 발생률·생존율·유병률 세 지표 모두 1위지만 진료비 비교에서는 상위 10위 안에도 들지 않아, "많이 발생하고 예후도 좋지만 치료 비용은 상대적으로 낮은 암"이라는 특징이 드러납니다. 반대로 폐암은 발생률·진료비 상위권이면서 생존율 상위 10위 밖에 있어 고부담·저생존 암종으로 구분되고, 진료비 1·2위인 "기타 암"과 유방암은 각각 복합적인 치료 비용 구조와 높은 유병률·양호한 생존율이 맞물린 결과로 해석됩니다.
